# model-painter

Десктопный 3D-пейнтер: рисуешь прямо по модели, а штрихи пишутся в PBR-карты материала (albedo, metallic, roughness).

Кисть работает на GPU (wgpu): попадание по мешу, штамп в UV активному слою, потом композит слоёв в текстуры материала. Размер карт — **1024×1024**.

Рендер и UI — `mega-render` и `mega-ui` (локальные крейты рядом с репозиторием).

## Что умеет

- Рисовать и стирать по сфере, кубу или загруженному **glTF / GLB**
- Три независимых стека слоёв: **Albedo**, **Metallic**, **Roughness**
- Кисть: цвет, радиус в мире, жёсткость, прозрачность
- Орбитальная камера и превью материала (Final / Albedo / Metallic / Roughness)
- Свет (ambient + directional, тени) и постобработка: env map, AO, contact shadows, SSGI, SSR, bloom, DOF, tonemap, color grade, vignette, grain, FXAA, fog

Экспорта текстур в файлы пока нет — это интерактивный пейнтер/превью.

## Как запустить

Нужен Rust и GPU с поддержкой wgpu. Пути в `Cargo.toml` указывают на соседние крейты `mega-ui` и `mega-render` (`../../../rust_lib/mega/...`).

```bash
cargo run --release
```

## Управление

| Действие | Как |
| --- | --- |
| Рисовать / стирать | ЛКМ по модели во вьюпорте |
| Вращать камеру | ПКМ (курсор захватывается) |
| Панорамировать | СКМ |
| Зум | Колесо |

## Панели

- **Viewport** — сцена, режим отображения
- **Brush** — Paint / Eraser, параметры кисти, выбор меша (Sphere / Cube / Model), кнопка **Open…** для glTF
- **Lights** — ambient и directional light
- **Effects** — постпроцесс
- **Layers** — карта (Albedo / Metallic / Roughness), слои: добавить, удалить, очистить, порядок, видимость, opacity

При загрузке модели краска сбрасывается на чистые слои, камера подгоняется под габариты меша.
